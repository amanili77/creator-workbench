# 创作者工作台操作指南

## 1. 安装

### Windows 图形方式

1. 安装 Python 3.11 或更高版本，并勾选 `Add Python to PATH`。
2. 把项目放到一个长期保留的目录，目录路径可以包含中文。
3. 双击项目根目录的 `首次安装.bat`。
4. 安装脚本会创建独立的 `runtime/` 环境、安装 Python 依赖，并下载 Playwright Chromium。
5. 安装成功后双击 `打开工作台.vbs`。

如果浏览器没有自动打开，可查看 `用户数据/当前端口.txt`，再访问 `http://127.0.0.1:端口号/`。

### 命令行方式

```powershell
py -3 -m venv runtime
runtime\Scripts\python.exe -m pip install --upgrade pip
runtime\Scripts\python.exe -m pip install -r requirements.txt
runtime\Scripts\python.exe -m playwright install chromium
runtime\Scripts\python.exe workbench.py
```

不希望自动打开浏览器时：

```powershell
runtime\Scripts\python.exe workbench.py --no-browser
```

## 2. 首次设置

打开左下角“设置”，建议按以下顺序完成。

### 名称与个人资料

- “工作台名称”显示在浏览器标题和侧栏。
- “助手名称”会用于界面文字和 AI 系统提示。
- “称呼、职业、经历、内容方向、目标受众、优势、表达风格”用于个性化简报与创作辅助。
- 不希望发送给 AI 的敏感资料不要填写；资料库中也可单独控制一条内容是否允许 AI 使用。

已有使用者升级后，本地 `用户数据/config.json` 会自动与新的默认字段合并，不会覆盖原资料。

### AI 模型

工作台支持 OpenAI 兼容的 Chat Completions 接口。

1. 填写接口地址，例如 `https://api.deepseek.com/v1/chat/completions`。
2. 填写服务商要求的模型名称。
3. 填写 API Key，点击“测试连接”。
4. 测试成功后点击“保存全部设置”。

输入框留空会保留已保存的 Key。真实 Key 不写入项目源码或示例配置。

### Obsidian

**不装 Obsidian 也能用** —— 工作台读写的只是普通 Markdown 文件，任何一个文件夹都能当知识库。装 Obsidian 只是为了有个图形界面来浏览和编辑。

**第一步，准备文件夹**。新建一个文件夹，在里面建两个子目录（名字必须一字不差）：

```
我的知识库/
├─ 维基/          ← 沉淀下来的知识，助手回答时优先读这里
└─ 原始素材/      ← 原始材料
```

**第二步，在工作台里配置**：

1. 开启 Obsidian 联动。
2. 填写 Vault 的绝对路径。
3. 可填写允许读取的一级目录，用逗号分隔，例如 `维基`；留空表示读取 Vault 内全部 Markdown 文件。
4. 点击“检查仓库”，确认后保存。

**联动是双向的**：

- 工作台里新增 / 修改选题和脚本 → 自动写到 `原始素材\工作笔记\01-创作中心\` 下。这个目录工作台会自己建，**不要手动改名或移动**里面的文件
- 工作台里删除的内容 → 移到 `99-回收站`，不会真删
- 在知识库里手改这些笔记 → 工作台读回数据库；冲突时以工作台数据库为准
- 问助手问题时，按 `维基/ → 工作台里的选题和脚本 → 原始素材/` 的顺序找依据

**不会喂给 AI 的内容**：`原始素材/` 里的 `00-` 开头导航页和 `参考资料/`、`维基/` 里的 `日志.md` 和 `约定.md`、带 `private` 标记的个人笔记、`99-回收站/`、以及超过 2MB 的单文件。

工作台只处理 Markdown 文件，并阻止通过构造路径访问 Vault 以外的位置。完整说明见 [README 的「本地知识库联动」](../README.md#本地知识库联动可选)。

### ima

1. 在 ima 获取 OpenAPI Client ID 与 API Key。
2. 开启 ima 联动并填写两项凭据。
3. 点击“测试 ima”，成功后保存。

工作台默认只列出当前凭据拥有的知识库；未配置时该功能保持关闭。

### 抖音收藏

1. 首次安装必须完成 Playwright Chromium 安装。
2. 在设置或灵感页点击“登录 / 重新登录”。
3. 在弹出的独立浏览器中扫码登录。
4. 登录成功后再同步收藏、运行 AI 分析。

登录状态保存在 `用户数据/抖音登录/`。不要上传或分享这个目录。自动采集默认关闭，避免后台静默运行触发账号风险。

## 3. 日常使用

- “总览”：查看简报、今日重点、账号和灵感概况。
- “工作计划”：添加任务并推进待办、进行中、已完成状态。
- “信源”：刷新热点，查看来源状态，按需运行 AI 解读。
- “灵感”：汇总 ima、抖音和本地灵感，并转入选题库。
- “选题库”：按账号推进点子、确认、写稿、拍摄和发布流程。
- “脚本库”：编辑脚本，并在配置 AI 后使用辅助功能。
- “我的”：维护允许工作台检索的个人资料和备忘录。
- “日记 / 身心”：记录本地日记、打卡与健康状态。

## 4. 数据目录、备份和迁移

默认数据位置是项目根目录下的 `用户数据/`。也可在启动前设置环境变量，把数据与源码彻底分离：

```powershell
$env:WORKBENCH_USER_DATA = "D:\CreatorWorkbenchData"
runtime\Scripts\python.exe workbench.py
```

在“设置 → 本地数据”中可以打开数据目录或生成 ZIP 备份。迁移到另一台电脑时：

1. 退出工作台。
2. 复制 `用户数据/` 或自定义数据目录到新电脑。
3. 重新执行安装，再把 `WORKBENCH_USER_DATA` 指向迁移后的目录（如使用自定义位置）。
4. Windows DPAPI 加密的 Key 通常不能跨 Windows 账户解密；请在新电脑重新填写 API Key。
5. 抖音登录状态也可能失效，需要重新扫码。

## 5. 更换助手形象

默认助手图片在 `static/assets/assistant/`。界面当前使用：

- `xiaoli-bust-base.png`：静止
- `xiaoli-bust-blink.png`：眨眼
- `xiaoli-bust-talk.png`：说话

保持文件名和透明 PNG 格式不变即可直接替换。三张图应使用相同画布尺寸和人物位置，避免动画跳动。更换素材时请确认你拥有公开发布和再分发权。

## 6. 常见问题

### 双击后没有反应

先重新运行 `首次安装.bat`。也可在 PowerShell 中执行 `runtime\Scripts\python.exe workbench.py` 查看报错。

### 端口被占用

程序会依次尝试 5210–5220。全部占用时，关闭冲突的本地服务后重试。

### AI 测试失败

检查接口地址、模型名称、余额和 Key 权限。接口地址可以填到 `/v1`，程序会自动补充 `/chat/completions`。

### Obsidian 保存设置时报目录不存在

关闭 Obsidian 联动，或填写一个当前电脑上真实存在的 Vault 目录。

### 抖音同步失败

先重新登录；如果平台页面已变化，查看终端日志并关注项目更新。不要反复高频重试。

## 7. 卸载

退出工作台后删除项目目录即可。如果 `WORKBENCH_USER_DATA` 指向其他位置，还需自行备份或删除那个数据目录。删除前确认其中没有需要保留的日记、脚本或备份。
